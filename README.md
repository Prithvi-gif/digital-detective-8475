# The Digital Detective
## Explore Your Computer • Build a Mini System Report

### About This Project

This repository contains my work for the Digital Detective Diwali Independent Learning Assignment.

The objective is to investigate how a computer works, practise Terminal operations, understand operating systems, explore how programs run, learn number systems, use Git and GitHub, and understand computer networking.

### Topics Learned

- Computer components and the Input-Process-Output-Storage (IPOS) cycle
- Terminal commands, file management, and permissions
- Operating system processes, memory, storage, and permissions
- How programs run and the difference between interpreters and compilers
- Decimal, binary, hexadecimal, ASCII, and UTF-8
- Git commits, branches, remotes, and GitHub pull requests
- Networks, DNS, ping, protocols, and how websites load

### How to Run the Python Programs

Python 3 is required. From the repository root, run:

**Hello World**
```bash
python3 mission-04-programs/hello.py
```

**Number Converter**
```bash
python3 mission-05-numbers-data/number_converter.py
```

The number converter asks for a decimal integer and displays its binary and hexadecimal representations.
