# Mission 1 — Know Your Computer

## Objective
Understand how a computer receives input, processes information, produces output and stores results. Identify hardware, software and computer-based systems.

## Task 1.1 — Trace One Activity Using IPOS

Activity: Typing and saving an assignment using Visual Studio Code.

| Stage | What happens | Hardware / Component |
|---|---|---|
| Input | I type text using the keyboard. | Keyboard |
| Processing | The computer processes keystrokes and updates the document. | CPU and RAM |
| Output | The typed text appears on the screen. | Display / Monitor |
| Storage | I save the document for future use. | SSD |

### Explanation
The activity starts when I enter text through the keyboard. The CPU processes the input, while RAM temporarily holds the data being used. The display shows the updated document. Finally, saving the document stores it on the SSD.

## Task 1.3 — Computer Systems Around You

| System | Main Purpose | One Input | One Output |
|---|---|---|---|
| ATM | Provides banking services | PIN entered by user | Cash dispensed |
| Smart TV | Provides entertainment | Remote-control command | Video and audio |

## What I Learned

1. A computer follows the IPOS cycle to process information.
2. Hardware consists of physical components, whereas software consists of programs and instructions.
3. The CPU processes instructions and RAM temporarily stores active data.
4. SSD provides long-term storage.
5. Computer-based systems are used in everyday activities such as banking, entertainment and traffic management.
